# Manual do Usuário — Le Cookí

## 1. Apresentação

O sistema Le Cookí foi desenvolvido para auxiliar na organização e no controle das operações da empresa.

Este manual apresenta, de forma simples e objetiva, como utilizar as funcionalidades disponíveis no sistema.

---

## 2. Central de Operações

A Central de Operações é a tela principal do sistema.

Ela foi criada para apresentar uma visão rápida das informações importantes para a operação diária da Le Cookí.

### Informações apresentadas atualmente

A tela possui quatro cards:

- Produção de amanhã
- Produtos abaixo do mínimo
- Itens para comprar
- Pedidos registrados

Também são apresentados:

- Pendências do dia
- Botão "Encerrar o Dia"

> **Observação:** Algumas informações exibidas atualmente são demonstrativas. As funcionalidades serão documentadas neste manual à medida que forem desenvolvidas e testadas.
